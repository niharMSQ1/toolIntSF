# ADP — integration (HRMS)

Code: [`app/integrations/categories/hrms/adp/`](../app/integrations/categories/hrms/adp/).

---

## API findings (official)

| Topic | Documented |
|-------|------------|
| **Auth** | OAuth 2.0 via **ADP Marketplace** application; default token URL `https://accounts.adp.com/auth/oauth/v2/token`. |
| **Data** | Human Resources API — sample path **`/hr/v2/workers`** (subscription-dependent). |

Defaults: `adp_api_base` → `https://api.adp.com` when not set.

---

## Configuration

```json
"configuration_data": {
  "client_id": "...",
  "client_secret": "..."
}
```

Optional: `adp_token_url`, `adp_api_base`, `access_token`, `skip_token_exchange`, `webhook_secret`.

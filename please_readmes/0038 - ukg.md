# UKG (Ultimate Kronos Group) — integration (HRMS)

Code: [`app/integrations/categories/hrms/ukg/`](../app/integrations/categories/hrms/ukg/).

---

## API findings

| Topic | Notes |
|-------|--------|
| **Auth** | OAuth 2.0 client credentials; **token URL and API base are product- and tenant-specific** (UKG Pro, Ready, Dimensions, etc.). |
| **Data** | Default REST path segment **`ukg_people_path`**: `/personnel/v1/people` — **override** to match your product’s OpenAPI. |

---

## Configuration

```json
"configuration_data": {
  "ukg_token_url": "https://.../oauth/token",
  "ukg_api_base": "https://...",
  "client_id": "...",
  "client_secret": "...",
  "ukg_people_path": "/personnel/v1/people"
}
```

Optional: `access_token`, `skip_token_exchange`, `webhook_secret`.
